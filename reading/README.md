# RAUM+ Reading Archive

黃英誠的個人閱讀網站，整理自 Notion「備忘錄 2.書｜完整整理」。

- 1,135 本書、13 個分類（同步至 2026-10-23，新增 1131–1135）
- 書名、作者與編號搜尋，互動書架、閱讀路徑、每本書獨立頁面
- 完整正文靜態保存於站內。最新 1131–1135 筆記位於 `notes/updates-20261023.json`；不依賴讀取 Notion 公開權限
- YouTube：播放器連接線上播放清單，影片目錄 724 支最後逐筆核對於 2026-09-26；尚無法核對的新影片不得擅自補入目錄
- 使用者的 Notion「完整內容｜單本」已匯入並編號新五篇，既有書目原編號不變
- 靜態 HTML / CSS / JavaScript，由 GitHub Pages 託管

本機預覽：在專案根目錄執行 `python3 -m http.server 4173`，開啟 `/reading/`。
